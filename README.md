# Родинне дерево — оновлення сервера

Тут лежать оновлення домашнього сервера «Родинне дерево».
Сервер сам перевіряє `version.json` кожні 3 години і, якщо версія новіша, завантажує `update.json`
(усі файли програми, крім Windows-рушія і папки `data`) та перезапускається.

Дані дерева, фото й облікові записи сюди не потрапляють — вони зберігаються лише на ПК з сервером.
